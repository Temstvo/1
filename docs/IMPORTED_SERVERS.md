# Серверы из serv-configs

В Appi добавлен экран `/app`: каталог, поиск по стране/названию/транспорту, фильтры, выбор профиля, скачивание JSON и копирование в буфер. Кабинет подписки доступен по `/dashboard`.

## Что импортировано

21 сентября 2026 восстановлены 52 исходных JSON из предыдущей версии репозитория в локальную папку `serv-configs`. Получено 48 уникальных профилей, 11 известных регионов; устранено 15 повторов (файл-коллекция содержит несколько профилей). Ошибок разбора нет.

Поддерживаются исходные Xray JSON, плоские описания VLESS и коллекции VLESS URI. Составные профили сохраняют DNS, routing, balancers и все outbounds. Сохраняются настройки TLS/Reality, gRPC/xHTTP/TCP. Локальные входящие прокси ограничиваются адресом `127.0.0.1`. Неполные и незашифрованные профили отклоняются.

Это импорт конфигураций, не проверка успешного VPN-туннеля. Доступность серверов и срок действия их ключей не подтверждены. Каталог не показывает придуманный ping, нагрузку или статус ONLINE. Подключение выполняется в Xray-совместимом клиенте после импорта JSON. Для xHTTP нужна версия клиента с поддержкой этого транспорта.

## Запуск и проверка без регистрации

Сборка из корня репозитория:

```powershell
corepack pnpm --filter @appi/backend build
node scripts/import-servers.cjs
corepack pnpm --filter @appi/frontend build
```

Нужна работающая PostgreSQL и заполненный `apps/backend/.env`, как описано в [GUEST_TESTING.md](GUEST_TESTING.md). В отдельных терминалах:

```powershell
node scripts/guest.mjs api
```

```powershell
node scripts/guest.mjs web
```

Если на портах 3100/3001 уже работает старая сборка, сначала завершите её в том терминале, где запускали, и повторно запустите команды. Откройте <http://localhost:3001/app>. Выберите профиль, нажмите «Скачать конфигурацию», импортируйте файл в VPN-клиент и включите подключение там. Email и пароль для локальной проверки не нужны: при экспорте создаётся гостевая сессия.

Скрипт `guest.mjs api` включает гостевые сессии и экспорт импортированных профилей. Скрипт `web` слушает только localhost. Это команды локального тестирования.

## На сервере развёртывания

- Передайте исходную папку `serv-configs` отдельно, по защищённому каналу. JSON с ключами исключены из Git и не должны попадать в public/static.
- Задайте backend `SERV_CONFIGS_DIR=/absolute/private/path/serv-configs`. По умолчанию используется папка в корне монорепозитория. В контейнере примонтируйте её read-only.
- Для разрешения экспорта установите `ENABLE_IMPORTED_VPN_ACCESS=true`. По умолчанию экспорт отключён. Для гостевого доступа также нужен `ENABLE_GUEST_ACCESS=true`.
- Перезапустите API после изменения файлов. `node scripts/import-servers.cjs` обновляет только безопасную копию метаданных frontend, после этого нужно пересобрать сайт.
- В коммит включены названия, регионы, форматы и идентификаторы профилей, но не UUID пользователей, адреса или полные конфигурации. API обновляет каталог из файлов, присутствующих именно на этом сервере.

Импортированные ключи управляются владельцем внешнего сервера, отдельно от платной подписки Marzban. Их экспорт не создаёт платёж и не выдаёт персональный управляемый доступ. Если требуется отзыв доступа по окончании подписки, используйте управляемую Marzban-интеграцию; общий готовый ключ этого не обеспечивает. Ранее опубликованные в истории Git ключи необходимо заменить у владельцев серверов перед коммерческим использованием.

## Проверки

- Backend/frontend production build: успешно.
- 68 модульных тестов: успешно, включая разбор профилей, дедупликацию и сохранение транспортных параметров.
- Четыре сценария с PostgreSQL: успешно. Новый сценарий проверяет публичность только метаданных, 401 без сессии, 403 при отключённом экспорте и корректный JSON с `Cache-Control: no-store` при разрешённом экспорте.
- 16 офлайн-проверок вёрстки Chromium: главная, `/demo`, `/login`, `/app` на 1440/768/390/320 px. Без горизонтального переполнения. Скриншоты `.local/ui/app-1440.png` и `.local/ui/app-390.png`.
- Запущенные локальные процессы используют предыдущую сборку; на момент проверки `/app` и новый API в них возвращали 404. Перезапуск веб-сервера ранее был заблокирован автоматической проверкой разрешений без указания причины. Полный браузерный сценарий экспорта и реальный VPN-туннель не заявляются проверенными.
