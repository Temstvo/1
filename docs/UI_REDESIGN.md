# Интерфейс Appi VPN

Главная, формы и кабинет используют общий графитовый фон, лаймовый акцент, локальный Inter, SVG-иконки и единые состояния элементов. Гостевой вход доступен с первого экрана.

## Реализация

- Next.js App Router, React 19 и TypeScript; основная разметка главной рендерится сервером.
- Клиентские компоненты используются для реальных тарифов, аккаунта и переключения инструкции по устройствам.
- CSS Grid, адаптивная типографика, градиенты и SVG вместо тяжёлых изображений или WebGL-сцены.
- Анимации transform/opacity, системный `prefers-reduced-motion`, видимый фокус, ссылка пропуска навигации и клавиатурное управление вкладками.
- Мобильная навигация и FAQ работают на нативном `details`; формы сохраняют HTML-валидацию.
- Тарифы и кабинет используют существующий API. Иллюстрации не изображают фактический статус VPN пользователя; вымышленных платежей, отзывов и метрик нет.
- Цвета PWA и SVG-иконка согласованы с интерфейсом. Обработаны страницы загрузки, ошибки и 404.

## Проверка

`corepack pnpm --filter @appi/frontend build` проходит с проверкой типов. Размер first-load JS главной по отчёту Next: 128 kB.

`node scripts/preview-static.cjs` открывает HTML/CSS production-сборки локальными файлами, без веб-сервера и JavaScript приложения. Проверены главная, `/demo`, `/login` на 1440, 768, 390 и 320 px; все 12 комбинаций без горизонтального переполнения. Проверяется загрузка Inter и работа нативного FAQ. Это проверка статической вёрстки, не end-to-end сценариев.

Для проверки гостевого входа на работающем стенде см. [GUEST_TESTING.md](GUEST_TESTING.md). Запуск веб-сервера из этой сессии заблокирован автоматической проверкой разрешений; причина не сообщена. Проверки с реальными YooKassa/Marzban требуют настроенной инфраструктуры.
