# DATABASE MODELS

25+ models created in Prisma schema:

Auth & Users:
- User (id, email, passwordHash, role, status, emailVerified, twoFactorEnabled, referralCode)
- Profile (userId, firstName, lastName, avatar, country, language, phone, timezone)

Sessions & Devices:
- Session (userId, tokenHash, ip, userAgent, deviceName, isActive, expiresAt)
- Device (userId, name, platform, osVersion, lastIP, lastSeen)

Subscriptions & Plans:
- Plan (name, description, price, currency, duration, trafficLimit, deviceLimit, protocols, regions, features)
- Subscription (userId, planId, status, startedAt, expiresAt, autoRenew)

Payments & Invoices:
- Payment (userId, subscriptionId, provider, transactionId, amount, status)
- Invoice (userId, paymentId, number, subtotal, tax, total)

VPN & Servers:
- Server (name, country, city, ip, protocols, status, cpu, ram, load, latency)
- VPNConfig (userId, serverId, protocol, config, publicKey, privateKey)
- Connection (userId, serverId, deviceId, protocol, connectedAt, bytesReceived, bytesSent)
- TrafficUsage (userId, serverId, download, upload, date, hour)

Other:
- Coupon (code, type, value, maxUses, expiresAt)
- Referral (ownerId, userId, commission)
- Notification (userId, type, title, message, read)
- Ticket (userId, subject, status, priority)
- TicketMessage (ticketId, senderId, message, isStaff)
- AuditLog (actorId, action, resource, ip, metadata)
- SecurityEvent (userId, type, ip, metadata)
